URN Audio Lyrics
================

PURPOSE
-------
Create lyrics/transcript text from a connected AUDIO source. When Embedded Lyrics are connected (normally from URN Load Audio), they are previewed first and the user chooses whether to use them. If they are ignored or absent, the node continues through the online identification/lyrics flow and uses Whisper only as the final fallback.

INPUTS / SETTINGS
-----------------
audio_input
- Required AUDIO input.
- Connect a standard ComfyUI Load Audio node or any other AUDIO output.
- Audio_out passes this input through unchanged.

Song Analysis
- True: enable song-specific analysis. This keeps BPM/music-feature analysis, temporary vocal isolation for Whisper fallback, and conservative Verse/Chorus structure detection.
- False: skip song-structure analysis and use straightforward Whisper transcription.

Gender Vocal Determination
- True: independently enable temporary Mel-RoFormer vocal isolation plus conservative pitch analysis for `female lead vocal` / `male lead vocal`.
- False: skip the vocal-gender determination stage. Song Analysis, BPM and Verse/Chorus detection can still remain enabled.

Include timestamps
- False: Transcript_Out is readable plain text.
- True: when LRCLIB provides synced lyrics they are converted to SRT-style text. Whisper fallback also produces SRT-style timestamps.
- Lyrics.ovh is plain lyrics only, so a Lyrics.ovh result remains plain text even when this option is enabled.

Get Online Lyrics
- True (default): after the embedded-lyrics check, use the interactive online identification/lyrics flow described below.
- False: embedded lyrics are still offered first; if absent/rejected, skip online lookup and use local Whisper transcription directly.

Embedded Lyrics
- Optional STRING input, normally connected from URN Load Audio -> Embedded_Lyrics.
- When non-empty, a scrollable preview is shown before any online lookup.
- Use Embedded Lyrics returns that text immediately as Transcript_Out.
- Ignore / Search Online continues to the normal online sequence (or Whisper when Get Online Lyrics is off).
- Stop Workflow cancels the current workflow.

Artist / Title / Album
- Optional STRING metadata inputs, normally connected from URN Load Audio.
- Artist/Title take priority over Artist - Title filename parsing for online song identification and MusicBrainz metadata.
- Album is used directly when the connected metadata matches the accepted Artist/Title.
- If Album is blank, MusicBrainz automatically selects the most appropriate official release group for the accepted recording. No additional validation dialog is shown.

Status line
- Display-only status directly below Get Online Lyrics.
- Shows stages such as Searching online song titles, Waiting for song selection, Getting genre, Analysing music, Getting lyrics, Transcribing lyrics, Detecting song structure and Complete.

ONLINE LYRICS FLOW
------------------
When Get Online Lyrics is enabled, the intended sequence is:

1. Automatic filename-based search
   - The node reads the CURRENT filename from the connected upstream Load Audio/file widget.
   - Changing the selected file in the same Load Audio node refreshes the filename even when the cable remains connected.
   - The filename is used to guess Artist - Song Title and produce an alphabetically sorted title list.

2. Automatic result panel
   - Accept: use the selected artist/title and continue online.
   - Reject / Manual Search: keep the workflow paused and open the manual search stage.
   - Stop Workflow: cancel the current ComfyUI workflow cleanly.

3. Manual artist-search stage
   - Enter an artist name in the Artist name field.
   - Click Search Artist (or press Enter).
   - Matching titles for that artist are loaded into the title dropdown.
   - Use Selected: use the chosen title and continue online.
   - Reject / Use Whisper: reject the manual search and fall back to Whisper.
   - Stop Workflow: cancel the current workflow.
   - If an artist search returns no titles, the user can edit the artist name and search again without resuming the workflow.

4. Confirmed-song online lookup
   - MusicBrainz metadata lookup runs for the confirmed artist/title and automatically fills Album when connected album metadata is unavailable.
   - LRCLIB is tried first for lyrics.
   - Lyrics.ovh is tried second.
   - If neither service supplies usable lyrics, the node offers/uses the manual-search path before Whisper when appropriate; Whisper is the final fallback.

LYRIC PROVIDER ORDER
--------------------
Overall sequence:
1. Embedded metadata lyrics (when connected) - user chooses Use or Ignore
2. LRCLIB for a confirmed song identity
3. Lyrics.ovh
4. Whisper only after embedded/online/manual paths have failed or been rejected

LRCLIB
- Free/no-key source.
- Uses confirmed artist/title plus source duration and album metadata when available.
- When Include timestamps is enabled and synced LRC lyrics are available, they are converted to SRT-style Transcript_Out.

Lyrics.ovh
- Plain lyrics fallback after LRCLIB.
- Does not provide synced timestamps.

Whisper
- Local final fallback transcription.
- With Song Analysis enabled, the node can use lyric repetition/timing and supporting beat/bar analysis to attempt conservative [Verse N] / [Chorus] labels.
- Structure labels are heuristic and are not official metadata.

MUSIC DESCRIPTION
-----------------
When a song identity is confirmed, Music_Description is a comma-separated STRING for downstream style/music prompting. Song Analysis controls the BPM/music-feature contribution, while Gender Vocal Determination independently controls the conservative lead-vocal label.

MusicBrainz contributes:
- Recording/release/artist genre and community-style tags when available.
- Automatic Album lookup for a confirmed Artist/Title when no matching embedded Album metadata is available. It prefers official Album release groups, then EP, then Single; Compilation, Various Artists, Live and Remix releases are rejected entirely. Releases credited to a different known artist are also rejected; among valid matches, original artist Albums are preferred over EPs and Singles, with edition variants deprioritized and the earliest suitable release preferred.
- The confirmed title is tried exactly first.
- If confidence is poor, a fallback search removes common release/remaster decorations such as `(2015 Remaster)`, `[Remastered]`, `- Remastered 2011`, `(Deluxe Edition)` and `(Album Version)`.
- Meaningful recording qualifiers such as Live, Remix and Acoustic are preserved.

MusicBrainz tag filtering (V9.73)
- Community-edited tags are filtered BEFORE they reach Music_Description.
- The editable blocklist is:
      urn_musicbrainz_tag_blocklist.json
- Matching is normalized and whole-word based where appropriate to reduce accidental substring matches.
- Built-in default blocked terms remain active if the JSON file is missing or malformed.

Librosa contributes only:
- measured BPM when Song Analysis is enabled
- `female lead vocal` or `male lead vocal` when Gender Vocal Determination is enabled and the isolated-vocal pitch result is sufficiently clear

Librosa does NOT add generic local guesses for genre, production style, timbre, groove, bass character, dynamic range or vocal register to Music_Description.

OUTPUTS
-------
Transcript_Out
- STRING containing LRCLIB lyrics, Lyrics.ovh lyrics or Whisper transcript, depending on which source succeeds.
- With Include timestamps enabled, LRCLIB synced lyrics and Whisper fallback are SRT-style timestamped text.

Duration_Seconds
- FLOAT containing the full source audio duration in seconds.

Music_Description
- Single-line comma-separated STRING using filtered MusicBrainz tags plus available BPM and optional conservative lead-vocal label.

Audio_out
- AUDIO passthrough of the exact connected audio_input.
- No gain, resampling or transcription-related modification is applied.

Artist
- STRING containing the artist identity the user accepted.
- Embedded Lyrics acceptance uses the connected Artist metadata.
- Online acceptance uses the exact artist from the selected online result.
- Empty when no artist/title identity was accepted before Whisper fallback.

Title
- STRING containing the title identity the user accepted.
- Embedded Lyrics acceptance uses the connected Title metadata.
- Online acceptance uses the exact selected song title.
- Empty when no artist/title identity was accepted before Whisper fallback.

Album
- STRING containing the accepted/automatically resolved album identity.
- Matching embedded Album metadata from URN Load Audio has first priority.
- Otherwise MusicBrainz resolves the recording and automatically chooses the most suitable Album/EP/Single without prompting the user.
- Empty when no confident album/release match is available.
